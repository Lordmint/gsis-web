How the system learns, day by day

None of this intelligence is guesswork. Each step writes down its numbers in the project files, and every refreshed build re-reads those numbers before it publishes anything — so the system's memory survives restarts and the cloud build sees exactly what the morning run saw.

It verifies its confidence

Every prediction is logged with the exact amount the system believed in it. When results arrive it compares belief to reality and writes down the gap. Right now 1 confidence band had enough finished matches to be checked — and it corrected itself where it was off.

It notices a league playing differently

The system watches goals-per-game in every league. It has flagged 4 leagues (Austrian Bundesliga, Liga Profesional Boliviana, Derde Divisie, South African First Division) as scoring faster than its own history suggests, and re-tuned its expectations for that league accordingly.

It tunes its standards per league

The bar a team must clear to become a pick has been tuned to 132 leagues individually, using each league's own track record instead of one one-size-fits-all rule.

It builds a strength model per league

A separate attack-and-defence model keeps score for 156 leagues, so 'how strong is this team today' is measured from its own recent matches, not a stale guess.

It is provably getting smarter

The system replays its own rules on past matches, pretending each week is live with no peeking at the future. Across 5327 replayed matches in 139 leagues it landed 55.4% of predictions in the early weeks and 59.5% later on — it has improved by +4.10 points as more evidence accumulates.

A day and night with the system
Three cloud refreshes a day

The cloud rebuilds the whole site at 04:25 UTC and re-checks it at 12:25 and 19:25 UTC — refreshing every tracked league, settling finished matches, checking its own past predictions, updating the weekly pick card and re-publishing the pages. It works whether or not this machine is switched on.

A desktop fallback, for now

A scheduled task on this computer also runs the same refresh at 06:00 daily as a safety net while the cloud proves itself; once it has been green for a week, the fallback is retired.

Before anything goes live

Every page is automatically checked against the results ledger. A dashboard that disagrees with a settled result is blocked — the publish would fail loudly rather than ship a wrong page.

Picks are frozen weekly

The pick card only grows when a genuinely vetted, priced opportunity appears. Once the weekend's last game settles it is final, and a fresh card starts the following Monday.

Every probability here is priced with a data-blindness tax: we have no live injury feed for soccer (−2pp on the favourite) and no prior meeting between most pairs (−1pp).
